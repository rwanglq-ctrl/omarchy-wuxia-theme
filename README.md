# 武侠 Wuxia

宣纸为底、浓墨为字、血色为印的浅色主题，深色版为 wuxia-night。壁纸选用已进入公有领域的中国古代侠义、人物画，截取局部铺满全屏。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-wuxia-theme
```
